# Binary-Search-Tree-Project-in-C++ DonationBox


This project is a **console-based Donation Box management system** implemented using a **Binary Search Tree (BST)** in C++. It allows users to donate money, manage donor records, and perform various operations like finding the highest/lowest donations, listing all donors, and deleting a donor.

---

## 📌 Features

- ✅ Add a donor with name and donation amount
- 📃 View all donor names (in alphabetical order)
- 💸 View all donation records (in order)
- 📈 Find maximum donation and donor
- 📉 Find minimum donation and donor
- 🗑️ Delete a donor and refund donation
- ❌ Exit the program

---

## 🛠️ Technologies Used

- **Language:** C++
- **Data Structure:** Binary Search Tree (BST)
- **IDE/Compiler:** Compatible with any C++ IDE (Code::Blocks, Visual Studio, GCC etc.)

---

## 🧠 How It Works

Each donor is stored as a node in the BST with their **name as the key** and **donation amount as the value**. Operations like insertion, deletion, and search follow typical BST logic.
